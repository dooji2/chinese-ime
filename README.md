**Chinese IME** is a Minecraft mod that helps you input Chinese characters using Pinyin, with additional support for **Jyutping** input for Cantonese speakers. It supports both **Simplified** and **Traditional** Chinese characters.

**Requires Fabric API. Also compatible with Forge and NeoForge, using [Sinytra Connector](https://modrinth.com/mod/connector), requires [Forgified Fabric API](https://modrinth.com/mod/forgified-fabric-api).**

## Features
- **Pinyin and Jyutping Support**: You can type in **Pinyin** or **Jyutping** for Cantonese, and the mod will suggest Chinese characters based on the letters you've entered.
- **Tone Support**: You can use tones by typing a digit at the end, and the mod will display tone-specific suggestions.
- **Simplified, Traditional, and Cantonese Support**: You can toggle between **Simplified**, **Traditional**, and **Cantonese** modes using a button on the chat screen.

## Usage
- Start typing **Pinyin** or **Jyutping** in the chat, and the mod will show you suggestions of Chinese characters.If you want tone-specific results, just add the tone digit at the end (for example, `wo3` for "我").
- Use the **up** and **down** arrow keys to navigate suggestions, and **enter** to select a character.
- You can also **scroll** through the list or **click** on the desired character to choose it.
- Toggle between Simplified, Traditional, and Cantonese modes using the button on the top-right corner of the chat screen.
